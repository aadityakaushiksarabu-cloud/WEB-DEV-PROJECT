# Expense Tracker

## Overview
The Expense Tracker is a web application designed to help users manage their finances by tracking their income and expenses. The application features a user-friendly interface that allows users to view their budget summary, add expenses, and visualize their spending habits through graphs.

## Project Structure
The project consists of the following files:

- **index.html**: Contains the structure of the expense tracker application, including a navigation bar for switching between the Home and Expenses tabs, as well as containers for displaying the budget summary and graphs.

- **styles.css**: Handles the styling of the application, including layout, responsive design for mobile and desktop views, and specific styles for the summary cards and graphs.

- **script.js**: Contains the JavaScript logic for the application, managing tab switching functionality, handling form submissions for adding expenses, and updating the UI with the current budget and expenditure data.

## Setup Instructions
1. Clone the repository or download the project files to your local machine.
2. Open the `index.html` file in your web browser to view the application.

## Usage
- Navigate between the Home and Expenses tabs using the navigation bar.
- In the Home tab, view your monthly budget and total expenditure.
- In the Expenses tab, enter the amount, select a category, and click "Save Expense" to add a new expense.
- The graphs will update automatically to reflect your spending habits.
